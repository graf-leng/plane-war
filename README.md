# ✈️ 飞机大战

一个用原生 **HTML + CSS + JavaScript** 编写的经典飞机大战小游戏。单文件、零依赖、无需构建，浏览器打开即玩。

## 🎮 游戏玩法

- **鼠标 / 触屏拖动** 控制飞机移动
- **方向键 / WASD** 也可以控制移动
- **自动射击**，专心走位躲子弹
- **P 键** 暂停 / 继续，**Enter 键** 快速开始 / 重开

### 👾 敌机类型

| 敌机 | 血量 | 得分 | 特点 |
| --- | --- | --- | --- |
| 🔴 小型机 | 1 | 100 | 速度快，直冲而下 |
| 🟠 中型机 | 4 | 300 | 波浪飞行，会瞄准射击 |
| 🟣 大型机 | 14 | 1000 | 皮糙肉厚，散弹攻击，必掉道具 |

### 🎁 道具（击落敌机概率掉落）

| 道具 | 效果 |
| --- | --- |
| **W** 火力升级 | 子弹升级（单发 → 双发 → 三连散射），被打中会掉一级 |
| **S** 能量护盾 | 抵挡一次伤害 |
| **L** 生命 +1 | 回复一条命（最多 6 条） |
| **B** 全屏清敌 | 引爆屏幕内所有敌机并得分 |

难度随时间递增：敌机越刷越快、越刷越密。历史最高分会保存在浏览器本地。

## 🕹️ 本地运行

用浏览器直接打开 `index.html` 即可，不需要任何服务器或依赖。

## 📁 项目结构

```
.

```
